# 主神也加班

一款无需安装依赖的单文件无限流文字游戏，直接打开 `index.html` 即可游玩。

## GitHub Pages

在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
合并到 `main` 后，工作流会自动发布，也可在 Actions 中手动运行 **Deploy GitHub Pages**。

发布成功后访问：https://ruilin520713.github.io/2/

## 阅读布局

游戏面板增高，剧情对话在中间独立滚动，章节标题和回答选项位于底部。
逐字显示时会跟随最新内容；向上滚动回看时停止自动跟随。
点击剧情可立即显示全文。小屏幕下底部选项过多时可独立滚动，查看全部回答。
